# T3 离线交付

学习功能为试用；本次没有连接真实达芬奇、没有访问 NAS、没有启动达芬奇渲染。全部 SDK 写入使用假对象验收；PostgreSQL 默认禁止写入。本文对应 T3，不替换现有旧版 B-roll Skill。

## 命令

入口：`python3 bin/broll.py <命令>`，非 UTF-8 模式会以 `-X utf8` 重启。

所有子命令支持 `--config 文件`、`--timeline 唯一时间线名`、`--project-dir 项目目录`、`--creator 姓名`。未指定时间线时只使用已打开工程的当前时间线。每条命令先检查 ffmpeg 可运行/架构/zscale、Python UTF-8、NAS 挂载、SDK 连接、数据库类型，再自动接管与读取学习差异。

- `status`：工程、数据库、主线和工作目录。
- `plan [--folder 目录] [--descriptions 描述.json] [--supplements 补充.json]`：候选清单、索引待描述、质量补充、匹配稿与依据哈希。匹配 JSON 是 T2 的 version/segments/face 合约，画面描述与语义匹配仍需实际看图。
- `apply --matches 匹配.json [--apply]`：默认演练；显式 `--apply` 才写时间线。演练也可准备本地片段，但不导入、不删片段、不保存工程。
- `adjust --spot 编号 (--use 1|2|3 | --segment ID | --remove | --reserve | --face on|off | --audio on|off) [--apply]`：点名局部调整，可重复 `--spot`。一个多镜语义段的后续镜头以 `编号-shot2/shot3` 记账，点名父编号会覆盖这组镜头；不会重排其他位置。
- `undo [--run ID] [--apply]`：默认演练。可撤销独立的旧运行；后续运行动过同一位置时必须先撤销后续。手动改过的片段拒绝删除。新增原声轨仅在清空后移除。
- `learn [--approve] [--verdict 原话] [--note 原话] [--forget last | --rule 规则名]`：认可为弱正例，原话保留出处，忽略不删除历史事件。
- `profile`：确定性档案；学习后输出三行差异说明。
- `at --playhead` 或 `at HH:MM:SS:FF`：审核线自动从 NAS 索引找到主线台账并映射，最多列三个候选。
- `clean [--yes]`：查询全工程媒体池与全部时间线引用；未引用的生成 MOV/WAV 及 JSON 移到待清理，`--yes` 明确授权删除（含上次移入、当前仍未引用的文件）。

失败返回码 2，输出“出错了 / 下一步”。参数名与数据契约字段保留程序标识。

## 配置与目录

默认配置路径 `~/.config/ai-talking-head-edit/broll.json`。至少需要：

```json
{
  "nas_mount": "fixtures/storage",
  "ledger_index": "learning/broll/台账索引.json",
  "learning_root": "learning/broll",
  "creator": "Creator",
  "allow_postgres_apply": false
}
```

以上是配置样例，本任务没有写入这些实际路径。测试全部用临时目录。

可选 `ffmpeg`、`lut_dirs`、`folder_lut_rules=[{folder,lut}]`、`fx_record`（fx 操作记录路径）、`coverage_confirmed`（用户明确确认下降超过 15 个百分点后才设 true）。`--timeline` 表示已明确选择该条谱系副本；未指定且两条同谱系线都被改过时停止并问一次。

V1 源路径在“视频素材/原片/素材/A-roll/Aroll/口播/拍摄”目录（可带数字前缀）时取该目录上层作为项目；否则要求所有 V1 源片共享父目录。不能唯一推出时，报错要求确认一次 `--project-dir`。工作目录是 `<项目>/B-roll_AI/`，符号链接解析后位于共享代码仓库内的输出被拒绝。

本机写入锁用 `flock`；锁文件保留 inode，进程退出会释放锁，避免删除锁文件后两个进程同时持锁。台账索引使用独立锁与原子替换，记录卷名、相对路径及学习状态。

## 接口

- `resolve_adapter.connect(name=None)`、`database_type(resolve)`、`read_snapshot(resolve, project, timeline)`、`media_pool(project)`、`timecode_frame(tc, fps)`。
- `resolve_adapter.Adapter(resolve, project, timeline)`：fx ResolveIO 的 B-roll 包装。所有未实测 SDK 语义集中在此文件的“待实测”注释。
- `workspace.infer_work_dir(model, project_dir=None)`、`write_lock(path=None)`、`register(index_path, ledger, work_dir)`。
- `writer.snapshot_hash(snapshot)`、`execute(io, plan, ledger, ledger_path, apply=False, config=None, lock_path=None, local=False)`、`undo(io, ledger, ledger_path, run=None, apply=False, config=None, lock_path=None)`（后半参数均 keyword-only）。
- `review_live.review_ranges(spots, start, end, pad=30, merge_gap=30)`、`identify(ledger, timeline_name, timecode, fps)`。
- `audio_clip.render_audio(candidate, directory, spot, source_start, frames, timeline_fps=29.97)`：生成那一处需要的 48kHz 双声道 WAV，精确样本数，越界拒绝；只有用户要求开原声才调用。
- `service.Session`：自动接管/学习、T2 候选与索引/匹配、单点调整与清理串联。`check_adjust_scope` 比较位置集合，不能仅靠数量相同绕过限制。

## 边界与设计选择

1. 唯一必要的 T1 修改是 `ledger.match_identity` 的同源多镜消歧：共享文件名+大小的候选不压过唯一的名前缀+文件证据；仍不用 SDK ID/路径/录制位置决定身份，真正重复仍“不确定”。原因已先写 T3_进度。
2. `guard_state` 保留真正写入或接管时的参数；自动学习更新 placement/S0 也不能把手改片段重新授权给删除操作。
3. 生成画面默认无音轨。生成片段或非直引原声需要开声音时，额外生成该处 WAV，再以 −5dB 链接放置；不重新生成画面。
4. 文件路径安全判断解析别名，保存/索引的路径保持调用方拼写，避免 /var 与 /private/var 混用。照片左右 offset 为 null。
5. 明确补充了 null 的质量字段算已人工看过且仍未知，不反复要求补充；旧索引真正没有字段时仍生成补充清单。
6. 缺 LUT 的主候选会在重新排布前剔除并尝试其他候选；全部不可用时保留既有片段或露口播，不能先删旧画面。
7. 回滚成功才说明“时间线已恢复原样”；若工程切换、用户并发手改或 SDK 失败使补偿无法核验，明确报告缺口并要求暂停检查现场，绝不假称成功。
8. 成功保留历史/审核副本；undo 不删已成功运行的对比副本。失败创建的副本会清理。没有 DRT 破坏性恢复回退，不让 fx 记录失效。
9. 用户限制仅新增文件和 bin/broll.py（必要 T1 修改先说明），因此未改 VERSION/CHANGELOG/旧 Skill/团队接入包，未提交发布存档。T3 可供 Claude 下一步实机验收；不是 v3 发布验收。
