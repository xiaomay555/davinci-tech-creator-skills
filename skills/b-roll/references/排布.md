# 排布：按句配画面，只改点名处

默认只给新空档配画面，保留已有 AI 片段和用户画面；“再配一次”不等于重排整片。口头意见只改用户明确点名的位置，学到的通用偏好用于新空档和下一条片子。

| 规则 | 为什么 |
|---|---|
| 连续字幕行组成语义段；一段1–3镜，内部换镜只在 V1 跳切点 | 一句话的意思连续，避免从半句话突然换画面 |
| 边缘只在±容差内吸附，优先跳切点；吸附不到用字幕行边界，默认容差5帧 | 不为贴跳切而超出容差缩回句中；档案可调整容差与优先级 |
| 自动排布当前默认单镜75–150帧，档案可改变上下限；表达方案按用途定，超出工具能力先说明 | 不拉长上一镜，不复制视频末帧凑时长，留口播也可以 |
| 不进用户画面、停用 V1、露脸句、章节/留空标记及学习保留位 | 保留她的画面安排；裁后边缘仍须合法且达到最短时长 |
| 同一素材段不重复；同源相邻镜源区间不重叠且至少相隔1秒 | 避免同一动作连续重播 |
| 主选用低于所有叠加层、区间空闲的最低画面轨 | 花字和人物抠像仍在上方；找不到轨就跳过，不新建视频轨 |
| 本次涉及的1–3帧口播/黑场缝必须消除 | 只能用真实余量补齐，不能侵入用户或保留位；补不了就缩回合法边界 |

画面主体居中、清晰优先；默认排除确定的失焦、主体被裁断。当前自动筛选仍排除创作者本人出镜（host）；人物（person）在样片（sample）用途允许，操作/场景用途排除；这些是工具限制，不能代替[画面组织判断](看图与匹配.md)。屏幕内显示的人物不算出镜，描述须写清。未知质量不猜测、不硬排除。

覆盖率按创作者档案 `rules.max_coverage`（或 `parameters.max_coverage`）覆盖，无档案设定时用全局默认1.0，表示不因比例停止，仍须逐处满足语义与保护规则，不要求铺满。明确点名的局部调整优先于此比例偏好。演练时核对覆盖率，下降超过15个百分点须先问一个问题，经确认才在本次配置中设 `coverage_confirmed=true`，不要永久当作已获授权。

用户删掉、换掉、停用或裁短 AI 片段留下的位置会成为保留位，再配不会自动补回。用户说“这里重新配”时，已有台账位置可用 `adjust --spot <编号> --face off --apply` 清除该处保留并重试候选；仍受手改保护。无台账位置或已删除且不能调整时先说明当前限制，不擅自清空保留位或重铺整片。

恒定29.97 fps普通视频和照片直接引用，池外普通素材从原路径导入；59.94等暂不支持直接放置的源帧率、HDR和可变/未知帧率才生成衍生片段，视频前后最多各2秒真实余量。衍生文件保留原文件名并在台账写转换原因；HDR转709，Log须有明确 LUT（色彩转换文件）依据，否则跳过并说明。未实机核验的不声称通过。
