# 配 B-roll

**禁止使用 Fusion**：除非剪辑的人明确要求，否则不用 Fusion；需要 Fusion 才能做的效果先问。详见 AGENTS.md。

## 用户手工定稿保护（所有工程、所有 Skill，2026-10-17）

**用户原话：“只要是我改过的素材都不要再改了。”用户手动制作或修改后的版本就是最终素材。**

- 适用于所有工程与所有制作 Skill，包括 A-roll、B-roll、字幕、花字、音效、图片、窗口、Fusion 节点及其参数。手动改过的整个素材／片段从批量修改、统一样式、重建、替换、清理和重新交付中排除，不能只保留几个改过的字段再重建它。
- 每次写入前以当前工程为准，对照上次 AI 写入记录辨认手改，并按片段 ID、源素材和当前范围记录保护清单。原本由 AI 创建也不代表可以继续接管；没有可靠基准或不能确定是否手改时，保留现状，不覆盖。
- 手工参考只供只读学习；不能修改参考本身，也不能用旧计划、默认参数或统一模板把手改版恢复成 AI 旧版。用户删除、替换、停用或拆掉的内容不得自动补回。
- 只有用户明确点名该对象并要求再次修改时，才调整其点名的内容，其他部分仍保留。“全片统一”“全部重做”“按这个模板”本身不授权覆盖手工定稿素材。
- 工具若不能排除受保护对象，就改用只处理已授权目标的局部方式；做不到则跳过该项，不能先整批覆盖再补回。写后核对保护对象没有变化；发现误改只撤销本轮造成的变化，不拿旧快照覆盖用户新改动。

给 使用者 选镜头或复盘手改时，读 [Looki图片对比学习的B-roll部分](../fx/references/visual-learning.md)：先确定这句要展示的动作、内容与证据，再选素材；人物实拍也可作 B-roll，不以覆盖率替代叙事。
共享工作台＝本 Skill 文件夹真实路径往上两级；读根目录 AGENTS.md，在工作台运行命令，输出留在片子项目目录。
用户先打开达芬奇工程，默认当前时间线；命令自动自检环境，plan/apply/adjust/learn 接管旧 AI 片段并学习已有改动，不要求 a-roll finish。
所有命令前缀为 `python3 bin/broll.py`；`status` 只读确认工程、时间线、工作目录，不创建目录或写台账、学习记录，推不出项目或创作者时一次只问一个问题。
配画面先读[看图与匹配](references/看图与匹配.md)、[排布](references/排布.md)，写入前读[写入与核验](references/写入与核验.md)；学习或纠错读[学习](references/学习.md)，报错读[故障](references/故障.md)。
用户说配 B-roll 即授权当前主线写入；时间线不明确、整片重铺、涉及她手改的位置或覆盖率降超15个百分点时先问一句。
## 保留原素材名称

插 B-roll 直接使用媒体池原文件夹里的原素材，按源入点裁切；保留源文件名、媒体池片段名和时间线片段名，方便用户反查原文件。不为插入而复制、重命名素材，或生成改名的替代视频；镜头说明、运行编号和 AI 归属写入备注或台账。

`apply/adjust` 普通视频和照片直接引用原素材；池外普通素材从原路径导入。HDR、可变/未知帧率及暂不支持直接放置的源帧率才转换，衍生文件名保留原文件名，台账记录源路径、源入点与转换原因；Log 缺可靠 LUT 时跳过。离线回归不代表实机验收，详见[写入与核验](references/写入与核验.md)。

## 她的说法 → 命令
表内 `<编号>` 由 `at` 定位，`<匹配文件>` 由 Codex 看图填写；调整前后只处理点名处，明确原话另记 `learn --note '原话'`。
| 她的说法 | 命令（由 Codex 执行） |
|---|---|
| 剪 B roll / 配 B-roll / 插画面 / 再配一次 | `plan` → 看第一层素材、填匹配；不足或用户要求补其他项目时 `plan --more` → `apply --matches <匹配文件>` 演练 → 同命令加 `--apply` 写入 |
| 这处（播放头 / 时间码） | `at --playhead` / `at HH:MM:SS:FF`；不唯一时最多列3处供选 |
| 这处换掉 | `adjust --spot <编号> --use 2 --apply`（或 `--use 3` / `--segment <素材段ID>`） |
| 这处不要 | `adjust --spot <编号> --remove --apply` |
| 这里留空 | `adjust --spot <编号> --reserve --apply` |
| 这句露脸 | `adjust --spot <编号> --face on --apply` |
| 这处开原声 / 关原声 | `adjust --spot <编号> --audio on --apply` / `--audio off` |
| 撤销刚才 | `undo --apply` |
| 旧版更好 | `undo --apply` → `learn --verdict '用户原话'`；撤销失败先停下 |
| 你学到了什么 | `profile` |
| 这次学错了 | `learn --forget last`；指定规则用 `learn --rule <规则名>`，不让用户找ID |
| 学习一下 | `learn` |
| 这版行了 / 可以了 / 定稿 | `learn --approve` |
## 汇报
只在保存、重开、读回通过后说“已铺 N 处，在原主线看”；局部修改另有短审核线，改动请回原主线。
演练、写入和局部调整都逐处列 `时间码｜句子｜素材文件名｜源入点（帧与时间码）`；跳过处只给一个具体原因：用户画面、保留位（她删/换/停用/剪掉/章节停用V1/点名留空）、露脸、已有AI，或裁后太短（实际帧数<最短帧数）；候选质量/黑名单/素材不足等按实际规则说明。另报覆盖率前后、匹配遵守率，以及被过滤的候选ID和规则名；按台账说明备选和原声状态。写入前必须打开演练输出的 `演练核图/<run>.jpg` 逐镜核对，核对通过再写入。
学习结果照实际输出三行，无变化也如实说：
- 这次学到的规则：……
- 素材与保留位：……
- 数值偏好：……
出错按“出错了：原因；下一步：由我处理的动作 / 需要你确认的一件事”说明；未核验不说完成，回滚未核验不说已恢复。
需要多项时按 a-roll → b-roll → fx；手剪口播也可直接配 B-roll。
学习功能试用中，第一条真片由她验收；离线测试不等于实机或用户验收。
