# 花字音效风格手册（初版 2026-10-11，随使用迭代）

以下为公开样式示例；用户当前要求与手改优先。

本轮依据（10-15 使用者；10-16共同规则确认）：
- 本次项目的已确认反馈：字体、单行等字号、原生着色3、默认静态。
- 本次项目的已确认反馈：数字列表、中线与少轨原则。
- 本次项目的已确认反馈：Pan/Tilt、有效波形先声后字、阴影边界。
- 本次项目的已确认反馈：当次调低的执行值不当永久标准；音量现以10-16 使用者的选段实际峰值不超过 -5 dBFS为准。

2026-10-16，使用者 明确授权将本轮36组图片对比写进总 Skill；[Looki图片对比学习](visual-learning.md)集中记录字形、字重、描边、阴影、排布与返修方法。此次采纳制作经验，不代表案例库定稿、采纳率统计或引擎参数更新。

## 通用规则（用户已定）

- **字号**：每种样式默认字号取用户手做花字的中位数，见 `engine/config/fx_styles.json` 的 `default_size`；可调，但不得低于默认的 75%。放不下就挪位置，不缩字；挪不开就交用户决定。（10-09）
- **安全距离**：照片标签、重点大字离画面边缘不少于短边的 3%，其他花字不少于 5%；不进底部 20% 字幕区。（10-09）
- **人物**：普通口播花字默认放真实人物框/遮罩旁的空处，不居中盖脸；字幕替代、明确顶部居中单独指定。下列轻遮挡规则仅用于明确位置等例外：字可以被人挡一点。被挡不超过 20% 时，自动抠人让人压在字前面；超过 20% 先把字挪开。手机、照片不能压，照片标签允许轻压照片顶部。（10-09、10-11）
- **轨道集中**：花字放在现有画面之上最低的一两条可用轨，跳过锁定、停用、冲突轨；音效从 A3 起复用一两条音效轨，A2 留给 B-roll 原声，不混人声。用户当次指定优先，计划 track 可覆盖；没有可用轨才新建命名轨。（10-15 使用者，10-16确认）
- **对比标签**（左右两张照片对比）：说到哪个词哪个标签才出现；那段没说到时按画面节奏先后出现。每个标签默认静态加一个音效，只有明确要求才加弹出动画，白字配主题橙 #FF6F00 底。（10-11）
- **字体与排版**：口播强调多用寒蝉体；B-roll 功能提示、小提醒、数字列表多用圆体（极影毁片圆），也可用仿宋、爱点风雅黑长体。用户指定和实际背景优先。口播左右各一行时不自动换行，两侧字号相同，位置结合片段 Pan/Tilt 与真实画面核对。（10-15 使用者）
- **默认静态**：无明确要求不加缩放、位移、淡入等关键帧；历史案例的弹出不推广为默认。（10-15 使用者，10-16确认）
- **阴影默认关闭**：用户要求时开启字体自带着色3，保留原生参数，不用固定小偏移代替；暗底可不用。镂空轮廓与阴影分开处理。（10-15 使用者）
- 太贴边的位置不照抄；空字只报告，不猜、不补；能查到原文且用户授权后才补。（10-16）
- 节奏前密后疏是这条片子的习惯，不硬凑数量。
- 颜色不用黄色，强调色用 #FF6F00。

## 花字类别

| 类别 | 什么话配 | 样式 | 位置 | 时长 | 音效 |
|---|---|---|---|---|---|
| 章节卡 | 分段开头，“第一步…”“认识焦段” | 序号行楷 + 主题寒蝉黑字，静态；明确要求时逐字显现（历史10例） | 纸底居中偏上 | 约 1.6 秒 | 打字声在起点；电子触摸提前约 23 帧作转场底音 |
| 数字/价格/分辨率 | 价格、2K/4K/8K（常是画面补充，原话未必说） | 寒蝉，深底白字、浅底黑字，默认无阴影、静态（历史5例） | 对应设备或图片上方空处 | 2–4 秒 | 一般不配 |
| 产品/应用/地点名 | 型号、App 名、地点（补全规范名称） | 圆体（极影毁片圆）或寒蝉，默认无阴影、静态（历史3例，样本少） | 机身上方、手机右上 | 约 3 秒 | 一般不配 |
| 镜头名称 | 超广角 / 主摄 / 长焦 | 寒蝉白字为主，可用镂空，带线指向镜头（11 例） | 镜头旁空处；三镜头组逐个出现 | 约 4 秒 | 每组一次电子触摸（起点后约 9 帧），不逐行重复 |
| 镜头规格小字 | 焦距、像素、光圈、中文描述 | 圆体、仿宋或爱点长体，静态（历史8例） | 镜头名称正下方，左对齐 | 随名称 | 不另配，和名称共用 |
| 倍率与焦段 | 0.6 倍 / 1 倍 / 3.5 倍、原生焦段 | 寒蝉白字大号，默认静态、无阴影（历史4例） | 手机左侧，规格小字在下 | 约 1 秒 | 连续三个：咻-起身 → UI 弹出 → 清脆鼠标点击 |
| 照片对照标签 | 参考图 / 直出、长焦 / 主摄 | 见上面“对比标签”规则 | 各自照片上方居中 | 到对比画面结束 | 每个标签一个，按连续顺序 |
| 观点与行动重点 | 行动建议、核心观点（“拍照”“拍视频”） | 寒蝉白字，默认静态（历史6例） | 人物两侧空处 | 约 1.2 秒 | 咻-起身 → UI 弹出 |
| 用途列举 | 平行列举（旅行 / 街景 / 合照） | 阿里妈妈数黑白字，静态依次出现、同点消失（历史3例，样本少） | 人物旁竖排 | 约 1.4 秒 | 咻-起身 → UI 弹出 → 清脆鼠标点击 |

| 数字花字 | 逐条口播的等长短句 | 蓝色 1️⃣2️⃣3️⃣ + 圆体短句，默认静态，随口播逐条累积 | 中间一行对齐画面水平中线；两行围绕中线；合并连续状态减少占轨 | 按每条对应首字出现，语义组结束消失 | 瞬态对齐首字；默认 -5 dBFS 峰值，可逐条指定增益 |

数字 keycap 字形需确认本机字体实际可见，不能把字体内部的 `????? Medium / Undefined` 当作缺字体。（10-15 使用者）

**花字文字怎么来**：照搬原词，或提炼成数字、短语。原话里没有的参数（价格、像素、光圈）不要编，要有可核实的资料才能加。

**音效其他规律**：相机快门多用在样张切换处，不跟花字绑定；音量现有 -8 / -5 / -3 / 0 dB 四档，历史数值是片段增益；当前默认按选段实测峰值算增益至约 -5 dBFS且不超过它，用户指定优先，不代表听感等响。

**可配但没配的**（样本少，未确认是否有意）：“电量只剩 8%”“日常拍摄用手机就够了”“焦段只是帮你构图的”。

## 10-16 使用者 补充（本任务已授权采纳）

依据：
- 本次项目的已确认反馈：目标点击/冲击瞬态与文字实际出现帧对齐，保留前导；工程外备份，保护独有修改和有效依赖后清理AI过程线。
- 本次项目的已确认反馈：对应口播首字起，标记只作提示；普通花字在人旁；多行清单同轨连续状态；章节标题不用标点，空格或换行，保留指定虚化底图与半透明大序号。
- 本次项目的已确认反馈：玻璃样式、颜色、填充透明度、模糊是不同维度。“保留第一版感觉但更透”只降低填充不透明度和模糊，不改颜色和版式。本次偏好中性白玻璃、白底约19%、较轻模糊（本次sigma 3），保留浅白细边；这是本次尚未定稿的方向，不是永久默认或已接受案例。

对话框保留原 UI，只改框内字符；连续段落左对齐、不手动断行。清单“逐行出现”与段落自然折行分开，不能据此重做整个 UI。
