# 口播花字 · 使用者

## 什么时候调用

用户说“口播花字”“按 AI剪视频 那组花字”“寒蝉体加原生着色阴影”时使用。2026-10-17 用户明确将此效果命名为“口播花字”，以后采用这一种阴影样式。用户仅要求学习时只更新规则，不编辑视频。

## 确定的外观与做法

- 原生剪辑页独立 Text+ 标题，保留模板信息及检查器文本、字体、字号控件。
- 字体：寒蝉端黑体，Resolve family `ChillDuanSans`，style `Black`；不是寒蝉有机体、手绘体或阿里妈妈数黑体。文字为纯白色，RGB 均为 1。
- 阴影：在文字模板的“着色”中启用已确认的第 3 元素 `Black Shadow`。**直接启用，其他参数全部保留，不重新设计。** 不另加 DropShadow、Blur、SoftGlow 或其他外部阴影节点；不把主文字柔化。
- 新标题优先复用这份确认模板的字体、白字和完整着色参数，再改文案；不得用旧的 Mac Studio 阴影参数或工具默认值覆盖这次示范。需要迁移模板时，按 [口播花字参数.json](口播花字参数.json) 的完整原生着色快照还原，之后只切换启用状态。
- 单纯开启阴影时只改 `Enabled3`；不要顺带调整距离、偏移、方向、柔化、不透明度或颜色。已有片段若另有用户手调，先保留；样式统一仅在用户明确要求时进行。
- 修改文字、起止或标题控件时，不改变这套样式。文字、位置、字号、时长和动画按本次画面及用户要求决定，不把示范的构图坐标和大小硬套全片。普通口播花字无灰色底条，未要求动态就静态。

## 本次确认的原生着色参数

下列是 2026-10-17 当前主线“花字_AI剪视频”用户示范的实际读值，**是确认模板的样本，不代表所有出厂 Text+ 的默认参数**。供跨工程复用和找回误改样式；不是每次“打开阴影”都重写这些值。

| 控件 | API 字段 | 已确认值 |
|---|---|---|
| 第 3 元素名称／启用 | `Name3` / `Enabled3` | `Black Shadow` / `1` |
| 不透明度 | `Opacity3` | `0.85` |
| 颜色 | `Red3` / `Green3` / `Blue3` / `Alpha3` | `0 / 0 / 0 / 1` |
| 柔和度 X／Y | `SoftnessX3` / `SoftnessY3` | `5 / 5` |
| 应用柔和度填充颜色 | `SoftnessOnFillColorToo3` | `0` |
| 辉光／柔和度混合 | `SoftnessGlow3` / `SoftnessBlend3` | `0 / 1` |
| 优先级 | `PriorityBack3` | `6` |
| 偏移 X／Y／Z | `Offset3` / `OffsetZ3` | `0.042 / -0.013 / 0` |

完整着色3参数见随附 JSON。`Level3=3` 是着色级别，不是界面显示的“优先级6”，不要混淆。阴影柔和度5仅作用于阴影，不能据此给文字填充添加模糊。

## 范围与优先顺序

这套规范适用于普通口播强调花字。章节背景虚化、玻璃字卡的玻璃底板、纸背景上的黑色复盘标题、B-roll 专用配色都不因“口播花字”自动改变。后续用户明确点名的新样式或手调示范优先；不再自行创造另一套口播阴影。
