# 使用者 动画默认配色 · 灰蓝纸纹

以下为可选的灰蓝纸纹示例配色；按本项目要求选择，保留用户已有配色。

## 颜色与用途

| 用途 | 源文件颜色 |
|---|---|
| 重点文字、线条、箭头、图标、进度条 | 灰蓝 `#496B72` |
| 主要文字 | 炭黑 `#292A28` |
| 次要文字 | 暖灰 `#66635E` |
| 底色 | 纸纹背景；兜底暖米色 `#CCC0AC` |
| 浅色卡片 | 米白 `#F4F0E7` |
| 卡片折角 | 浅米灰 `#DED8C9` |
| 滑块圆点 | 米白 `#F6F3EC`，灰蓝描边 |
| 次要图形线 | `#B4AFA2` / `#C4BFB2` |

原片使用纸纹图片，背景明暗本来有纹理变化，`#CCC0AC` 仅是兜底底色，不应拿一整块纯色代替原纸纹。透明描边与轨道线按原样复用：例如 `#857F7155`、`#706B5D35`；不用高饱和新颜色补足层次。

## 应用方式

- 将强调色统一为实际源值 `#496B72`。这是低饱和灰蓝，带一点青灰倾向；不要只凭“蓝色／绿色”的口头名称另选色，也不改回夕阳粉、橙色或饱和蓝。
- 主文字保持炭黑，说明文字保持暖灰，重点和图形才用灰蓝，避免所有文字都染成主题色。
- 新动画与相邻已有动画保持同套颜色关系。修改内容、图标、排版或动效时，不顺手另配一套颜色。
- 这次授权学习的是颜色，不把示例的字体、构图、时间、台词或动画曲线强制推广到所有动画。字体和动作依用户另行确认的规范处理。
- 口播花字仍按“口播花字”的白字与原生着色阴影；玻璃花字仍按玻璃字卡定义。不得把动画灰蓝色套到这些白字上，或把纸背景黑色复盘标题染色。
