# AI 剪辑

共享工作台 = 本 Skill 文件夹真实路径往上两级（即本仓库根目录）。

| 用户想做什么 | 读哪个文件 |
|---|---|
| 剪 A roll、剪口播、选重录、修气口/吞字/跳切、字幕校对、审核网页、保存到达芬奇、只转文字 | `skills/a-roll/SKILL.md` |
| 在当前达芬奇时间线剪 B roll/配 B-roll/插画面、这处换掉/不要/留空/露脸/开原声、撤销刚才、旧版更好、学习一下/这版行了/你学到了什么/这次学错了 | `skills/b-roll/SKILL.md` |
| 加花字、加音效、字卡（含口播花字、玻璃字卡、动画配色）、标注、定稿入库 | `skills/fx/SKILL.md` |
| 整理经验、看看攒了哪些经验 | 在用户指定的数据目录汇总，不读取作者私人记录 |

只读需要的那一个子 Skill；用户一次要求多项（如“剪好再配 B-roll”）按 a-roll → b-roll 顺序，做完前一项再读下一项。判断不了是哪项时用一句话问用户。花字音效按 fx Skill 先读标记和画面、制定计划；用户同意范围后才执行制作。

加新子 Skill：在 skills/ 下新建文件夹，在本表加一行，在 bin/install_skill_mac.sh 的列表里加名字。
