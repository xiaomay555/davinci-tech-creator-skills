# 达芬奇脚本接口实测记录

三个分项（a-roll、b-roll、fx）在 Resolve Studio 21.1.1 上实测过的接口行为。写入达芬奇的代码和临场操作先查这里；换了达芬奇版本要重新验证，不要直接套用。来源见各条末尾的经验文件日期。

## 放片段

- **`AppendToTimeline` 的 `endFrame` 不含结束那一帧**：要放 N 帧，传 `endFrame = startFrame + N`。传 `N-1` 会每段少一帧，并留下一帧空隙。读回的 `GetSourceEndFrame` 仍可能显示 `N-1`，不能拿它判断。（10-11、10-14，三个分项都遇到过）
- **源帧读数有浮点误差**：`GetSourceStartFrame` / `GetSourceEndFrame` 可能差一帧，核对源偏移用 `round(GetLeftOffset(True))` 和 `GetDuration`。`GetLeftOffset` 的单位是时间线帧，30 fps 素材放进 29.97 时间线时不能直接和源帧号比较；浮点 `endFrame` 会少一帧，应向上取整后读回确认。（10-11、10-14）
- **静态图片放不出指定长度**：请求 620 帧只得到默认的 150 帧（有时只有 30 帧）。这是接口的限制，不是达芬奇软件的限制：用户在剪辑页可以直接拉长图片。接口改不了时长时，尽早改为在剪辑页修剪（或请用户拉一下），不要反复试接口；视频要定格延长时用静帧或图片。（10-11、10-15）
- **`InsertFusionTitleIntoTimeline` 会推移同一轨后面的片段**：插入前先确认插入点之后的同轨位置是空的。（10-15）
- **`CreateTimelineFromClips` 继承工程的默认帧率**：工程默认 24 fps、原片 29.97 时，建出来的时间线是错的。建线前先核对帧率。（10-14）
- **不能先试、出错再修**：第一次写入短片段后，立刻读回边界，确认没有空隙再批量追加。

## 素材与属性

- **媒体池套 LUT**：`SetClipProperty('Input LUT', 名称)` 要写 LUT 的显示名称，不带 `.cube` 扩展名（带扩展名会返回 False）。这是输入 LUT，不是调色节点上的 LUT。（10-14）
- **改片段名**：`SetClipProperty('Clip Name', …)` 返回 False，改用 `SetName`。但 B-roll 的规则是不给原素材改名。（10-11）
- **读轨道开关要在活动时间线上读**：对非活动时间线调 `GetIsTrackEnabled` 可能返回 False。（10-14）

## 导入导出

- **导入原生 DRT 会改掉项目宽高**：会把项目宽高改成时间线的宽高。导入前记下项目设置，导入后读回比较，变了就恢复。（10-11）
- **MCP 的写操作会自动生成 `_archived` 副本时间线**：已知的有 `create_subtitles`、加轨、轨道名、轨道开关、链接、`set_clip_enabled`。写入改走 DaVinciResolveScript 直连；用户要求工程里只留一条时间线时，要清掉这些副本。（10-07、10-14）
- **字幕文字没有可用的修改接口**：字幕片段 `SetName` 返回 False。要改字幕文字，导出 DRT、只改字幕的 Name 再导入，保留原生样式和时间点。（10-14）
- **中文工程要设 locale**：直连 SDK 保存中文工程，需要 `en_US.UTF-8` 的 locale（脚本同时加 `PYTHONUTF8=1`）。（10-15）

## Fusion 与标题

默认禁止使用 Fusion（见 AGENTS.md）；下面 Fusion 相关条目只在剪辑的人明确要求用 Fusion 时，或只读已有 Fusion 片段时参考。

- **Text+ 标题要保留模板标识**：脚本改写标题时，要保留 `CustomData.TEMPLATE_ID = "Text+"`。丢了它，剪辑页检查器就只剩标题栏，看不到文字控件。（10-16）
- **Fusion 参数改完可能没存进去**：创建节点后直接改参数（例如 Shadow），内存里读得到，导出 DRT 再导入却变回默认值。用 `StartUndo` / `EndUndo(True)` 包住参数修改后，保存重开能保留。原因未查明，只当操作方法用。（10-14）
- **`SaveSettings()` 不带参数会失败**：Python 桥里不带路径调用，会遇到 OrderedDict / null 参数错误。改用 `SaveSettings(path)` / `LoadSettings(path)`。（10-15）
- **改 DRT 时，`.comp` 里的 Loader/Saver 不等于 MediaIn/MediaOut**：要用 `ImportFusionComp` 正确导入转换，再确认节点的注册类型；只读到文字的值，不能证明画面能显示出来。（10-16）
- **曲线的 RH/LH 是相对位移**：`BezierSpline.SetKeyFrames` 的 RH/LH 参数是相对位移，传绝对帧坐标会让曲线越界。（10-15）
- **整个合成删不掉时，只删新增节点**：`DeleteFusionCompByName` 可能返回 False。此时删掉新增的节点，恢复 MediaIn → MediaOut 直连；不要删输入节点，否则会黑屏。（10-15）
- **关闭的着色元素读回可能是 None**：关闭的着色元素保存重开后读回 None，这是懒加载，不算样式丢失；核对时只比较启用的值。（10-08、10-15）

## 渲染

- **变速片段尾部渲染失败**：TimeStretcher 在默认 Blend 模式下会读到相邻的无效帧，导致渲染失败；改成 Nearest 后通过。静帧看着正常，不能证明编码导出能通过，要用短段实际导出来验证。（10-15）
- **`LoadRenderPreset` 不会恢复用户的输出设置**：目标路径、文件名和范围都不会恢复。诊断完要显式恢复，并清掉临时渲染作业。（10-15）

## 界面操作（CUA）

- 达芬奇里有对话框（例如键盘自定义）开着时，MCP 调用会返回 None，要先关掉对话框。锁屏后无法连续播放和截屏。截图冻结、或者播放开关变了但时间码不走，都不算已经播放过，必须如实标“未听审”。（10-11、10-14、10-15）
- 键盘 `D` 键会停用片段，不能当“选择”用；在界面里改时长要真的键入数值，再读回确认。（10-15）
